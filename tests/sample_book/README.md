# About This Book

This is a sample book created to test the **mark2web** static website generator.

It demonstrates that `README.md` is converted into the `about.html` page.

## Project Goals

- Provide a beautiful reading experience similar to [burgeonbook.org](https://burgeonbook.org/).
- Support **Progressive Enhancement** so the website works without JavaScript.
- Be easy to deploy on GitHub Pages, Netlify, or Cloudflare Pages.
